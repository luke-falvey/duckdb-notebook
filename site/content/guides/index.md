# Guides

Each guide covers one task, with real notebooks and the output they produce.

| Guide | For when you want to |
|---|---|
| [Writing a notebook](writing.md) | Know the cell kinds, names, dependencies, prose with live values and cell options |
| [Inputs and parameters](inputs.md) | Let readers change values with widgets, or pass values from outside |
| [Charts](charts.md) | Chart a result, pick a chart type, add reference lines and notes |
| [Selections and cross-filtering](selections.md) | Brush or click a chart and have other cells follow |
| [Reading and presenting](reading.md) | Hide code, lay cells out on a grid, make a page that reads well |
| [Keeping results](cache.md) | Reopen a notebook showing its last results, or prepare them in a job |
| [Storing notebooks in a database](storing.md) | Keep notebooks and their history inside a DuckDB file |
| [Exporting and sharing](exporting.md) | Send HTML, PDF, Markdown, plain SQL or data files |
| [Running headless and in CI](headless.md) | Run notebooks from SQL, scripts and GitHub Actions |
